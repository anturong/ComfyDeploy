# ComfyUI 扩展安装器 功能介绍
ComfyUI 扩展安装器是一款可视化工具，专为简化 ComfyUI 自定义节点（扩展）的安装流程设计，解决了手动安装扩展时的环境配置、网络加速、依赖处理等痛点，适配 Windows/macOS/Linux 系统，核心功能如下：

## 一、核心安装能力
### 1. 多方式添加扩展包
- **拖放添加**：支持将 ZIP 格式的扩展包直接拖入界面（需安装 `tkinterdnd2`，未安装时会提示）；
- **手动选择**：通过“添加”按钮批量选择本地 ZIP 扩展包；
- **自动扫描**：点击“扫描”按钮，自动检测当前目录下所有 ZIP 格式扩展包并添加；
- **缓存恢复**：关闭工具后重新打开，会自动恢复上次未安装的扩展包列表，避免重复操作。

### 2. 智能路径配置
- **安装路径设置**：指定 ComfyUI 根目录，扩展会自动安装至 `<根目录>/custom_nodes/` 下，支持“浏览”选择路径；
- **Python 自动检测**：根据 ComfyUI 路径自动检测虚拟环境（venv/.venv）或系统 Python 解释器，显示 Python 版本，确保环境匹配；
- **路径缓存**：保存上次设置的安装路径、Python 路径，无需重复配置。

### 3. 灵活的安装选项
| 选项 | 功能说明 |
|------|----------|
| 安装前升级 pip | 自动升级 pip 到最新版本，避免旧版 pip 导致的安装失败 |
| 使用国内镜像加速 | 启用后自动配置：<br>- pip 源切换为清华大学镜像；<br>- GitHub 依赖通过镜像代理下载（zip 方式绕过 git clone）；<br>- 自动检测本地代理（支持 7890/7891/1080 等常用端口），优先使用代理加速 |
| pip install -e 安装 | 针对含 setup.py/pyproject.toml 的扩展，以可编辑模式安装，适配需编译的扩展 |

## 二、网络优化与依赖处理
### 1. 网络适配策略
- **代理检测**：自动扫描本地常用代理端口，检测到则自动配置 git/pip 代理；
- **镜像降级**：无代理时自动切换为国内镜像模式，解决 GitHub 克隆失败、pip 下载慢的问题；
- **环境恢复**：安装完成后自动恢复系统原有的代理、git 配置、pip 源，不污染本地环境。

### 2. 智能依赖处理
- **Requirements 解析**：自动扫描扩展包内的 requirements.txt（忽略 venv/.git 等无关目录）；
- **GitHub 依赖转换**：将 requirements.txt 中的 `git+https://github.com/` 格式依赖，自动转为镜像下载 zip 包安装，避免 git clone 失败；
- **多分支尝试**：GitHub 依赖下载时自动尝试指定分支、main、master 分支，提高成功率；
- **失败重试**：单独记录依赖安装失败项，支持一键重试，无需重新安装所有扩展。

## 三、可视化与交互体验
### 1. 扩展列表管理
- 列表展示扩展包名称、文件大小，支持勾选/取消勾选、全选/取消全选；
- 可删除不需要的扩展包，实时显示已选择数量/总数量。

### 2. 安装过程可视化
- **进度条**：实时显示安装/重试进度；
- **日志面板**：详细记录每一步操作（解压、依赖安装、网络配置），按不同级别着色（成功/错误/警告/信息），附带时间戳；
- **状态提示**：底部实时显示当前操作（如“解压中”“升级 pip”“下载 GitHub 依赖”）。

### 3. 便捷操作
- **一键安装**：点击“开始安装”自动完成解压、依赖安装全流程；
- **重试失败项**：安装完成后若有失败项，一键重试仅处理失败的依赖/扩展；
- **打开安装目录**：直接打开 ComfyUI 的 custom_nodes 文件夹，方便查看已安装扩展；
- **异常提示**：安装超时、网络错误、Python 未找到等场景均有明确提示。

## 四、容错与稳定性
- **解压容错**：支持扩展包内单层/多层目录结构，自动识别扩展根目录；
- **超时处理**：pip 安装超时设为 10 分钟，避免卡死；
- **临时文件清理**：安装完成后自动删除下载的临时 zip 包、解压目录；
- **异常捕获**：关键步骤（解压、pip 安装、网络请求）均有异常捕获，避免工具崩溃。

## 五、使用流程（极简）
1. 选择 ComfyUI 根目录（自动检测 Python）；
2. 添加/拖入扩展 ZIP 包；
3. 勾选需要的安装选项（默认启用镜像加速、升级 pip）；
4. 点击“开始安装”，等待完成（失败可点击“重试”）；
5. 重启 ComfyUI 即可使用扩展。

该工具彻底简化了 ComfyUI 扩展的安装流程，尤其解决了国内用户访问 GitHub 慢、pip 下载依赖超时、手动配置环境复杂等核心问题，适合各类技术水平的用户使用。
